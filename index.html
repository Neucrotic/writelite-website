WriteLite in use
The premise

WriteLite is built by one developer who is also a writer. It is a tool with a single conviction — let the writer get their ideas out as fast as they can type them. No waiting for a load screen. No wondering where the files went.

Most writing software does too much, starts too slowly, or insists on keeping your files in a format it controls. WriteLite will not.

Speed

WriteLite targets a startup time under half a second — faster than most apps finish their loading screens. When you have an idea, the gap between thought and page matters. WriteLite makes that gap as small as possible. The speed of typing meets the immediacy of pad and pen. WriteLite is ready when you are.

Your files are yours

Every document is saved as a .wlite file— markdown text underneath, which means any word processor or writing app on any computer can open it. There is no lock-in. Your files belong to you, not to WriteLite.

WriteLite does not care where your files live. It opens them, saves them, and asks nothing else. What you write is already a file on your computer.

Put your project folders in the cloud or save them to a USB for easy backup, and tell WriteLite where you're keeping them.

Focus mode

Pour your stream of consciousness onto the page in a way that suits you. Use Full-Screen mode to make distractions vanish.

Free, and why

Writing shouldn't cost a subscription, so WriteLite is free with no expectations, no obligations, and nothing withheld. Built by one writer who codes, consider this a gift from me to you. The development of WriteLite is sustained by donations alone. It has no locked formats or paywalls and does not store any of your data on the cloud. Your files belong to no platform.

What you pay for is what you're asking the world to make more of. If this app gave you something, there's a way to give something back. No pressure, but the door is open. This is how I keep the lights on.

A promise

WriteLite has no server, no account requirement, and no telemetry. Nothing you write leaves your machine. WriteLite will never read your documents, request access to your files beyond what you open yourself, or store anything outside your own disk. What you write is yours, completely and permanently.

Patch Notes

v1.0.4 11 August 2026
  • .wlite files are markdown + some HTML under the hood. This patch cleaned up the file format so the raw markup view is cleaner.
  • The .wlite icon appear less squashed
  • Users can now set their own default settings per file. Per project settings coming soon.
  • System theme option available from the menu bar
  • Fixed an issue where files would occasionally open WriteLite at the wrong project
v1.0.3 15 July 2026

This patch brings a new welcome experience. The first time you open WriteLite it now walks you through the app and lets users set their theme preference from the start.

  • Choose your theme during setup — Dark, Light, or System. System follows your computer’s own appearance setting and switches along with it while the app is open, and WriteLite now opens in the right theme straight away instead of flashing the wrong one first.
  • Blank lines you deliberately leave in a document no longer disappear when it reloads.
  • Fixed a bug that prevented sorting files by “Last Updated”.
  • Fixed markdown rendering inconsistencies across .wlite and .md files.
  • Fixed some awkward UI bugs that left old information on the page.
  • Improved support for imported files.
  • Known issue: very large documents (100,000+ words) are slow to open, and the window may stop responding while they load.
v1.0.2 12 July 2026
  • The File View window now has a full menu bar on macOS, matching Windows.
  • Settings has moved into the menu bar, so it is quicker to reach.
  • WriteLite now reopens the files you had open in File View when you last closed it — you can turn this off in Settings.
  • You can now close individual file tabs with the × button or by right-clicking, instead of closing the whole window.
  • On macOS, double-clicking a file in Finder — or dragging it onto the app — now opens it directly, instead of launching to the default window.
  • Links now stand out in the accent colour.
  • In the light theme, faint and disabled text is clearer and easier to tell apart from ordinary text.
v1.0.1 11 July 2026
  • Switching between projects now opens the correct document instead of leaving the previous file on screen, and each project remembers the last file you had open.
  • Links you add are kept when you reopen a file — previously they could vanish on reload. You can also type a link inline as [text](https://…) and it becomes clickable.
  • Imported files are better supported — .txt and .md files now open alongside .wlite.
  • Importing now offers a “keep original format” option so files come in as-is.
  • Re-adding an existing project no longer resets its settings — sort order, expanded folders, and name are preserved.
  • Fixed a problem where renaming a project could break it and make it show as “missing” after a restart.
  • The formatting toolbar is now centred and scrolls when there isn’t room to show every button.
  • Entering and leaving fullscreen is now a smooth transition.
  • On macOS, the fullscreen shortcut hint now correctly shows ⌃⌘F — it previously listed a shortcut that did nothing.
  • Renamed the “Documentation” menu item to “Guides & How-Tos”.
